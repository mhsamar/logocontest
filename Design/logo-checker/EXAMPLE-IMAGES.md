# Logo Checker example images

Neutral placeholder logos made for logocontest.bd (owner, 2026-10-13). They are made-up marks, not real brands,
used only on the public /logo-checker page to show how the checker works.

To use your own example images, replace these files with the same names (SVG, 200 x 200 or any square size).
Never put a real client's logo here.

- sample-01 to sample-03: the three "Try a sample" logos (and sample-01 is "Your logo" in the sample report)
- sample-04 to sample-12: look-alikes, floating logos and the design picker
